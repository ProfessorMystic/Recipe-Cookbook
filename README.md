# 🍳 Recipe Cookbook

**Recipe Cookbook** is a full-stack web application that allows users to create, browse, update, and manage recipes.  
The project features a **FastAPI backend** for a RESTful API, an **SQLite database** for persistent storage, and a **simple frontend** built with HTML, CSS, and JavaScript.

---

## ✨ Features

- 📖 Add new recipes with a title, ingredients, and instructions  
- 🔍 Search recipes by keyword (title or ingredients)  
- ✏️ Edit existing recipes  
- 🗑️ Delete recipes  
- 📑 Interactive API documentation via **Swagger UI** and **ReDoc**  
- 💾 Persistent recipe storage using SQLite (`recipes.db`)  
- 🌐 Lightweight frontend to interact with the API  

---

## 🛠 Tech Stack

- **Backend:** [FastAPI](https://fastapi.tiangolo.com/), [SQLAlchemy](https://www.sqlalchemy.org/)  
- **Database:** SQLite (default, can be swapped for PostgreSQL/MySQL)  
- **Frontend:** HTML, CSS, Vanilla JavaScript  
- **Server:** [Uvicorn](https://www.uvicorn.org/)
